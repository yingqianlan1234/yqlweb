# 栖点 · Brave 新标签页扩展

1. [下载 qidian-newtab.zip](https://github.com/yingqianlan1234/yqlweb/raw/refs/heads/main/dist/downloads/qidian-newtab.zip)，解压到一个长期保留的文件夹。
2. 在 Brave 地址栏输入 `brave://extensions`。
3. 打开右上角“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择直接包含 `manifest.json` 的文件夹，再打开一个新标签页。

更新时把新版文件解压覆盖到同一个文件夹，在扩展管理页点击重新加载；不要先卸载，以免丢失扩展本地数据。

## 从网页版迁移

先在网页版“设置 → 数据迁移”导出设置，再在扩展中导入同一个文件。支持设置、快捷网站和搜索历史；壁纸与目录授权需要在扩展里重新选择。迁移不会删除网页版的数据。

## 功能与隐私

- 搜索联想统一由必应提供，输入停顿后才请求；实际搜索仍使用你选择的引擎。可在“搜索与隐私”里关闭。
- 搜索历史只保存本页实际发起的关键词搜索，最近 30 条，支持单条删除、清空、关闭记录；不读取浏览器的全局浏览历史，直接输入的网址不记入搜索历史。
- 常用网站在添加或编辑时可填写自定义分类；标题下选择分类展开或展开全部，每页最多 10 个，支持分类内跨页拖动。关闭搜索历史后，空搜索框不显示历史窗口，联网联想仍由自己的开关控制。
- 扩展可直接读取本机书签，点击连接后选择添加，无需另装书签连接扩展；不会修改书签。
- 网络权限只包含必应联想、今日热点与一言三个服务域名。联网数据来自各服务，离线时仍可使用历史、快捷网站、设置和本地壁纸。
- 目录选择仍受浏览器的文件授权约束；不能静默扫描硬盘，也不运行 Wallpaper Engine 的场景或程序。
- 本扩展面向电脑端 Brave / Chromium 浏览器；手机继续使用网页版。不替换无痕窗口的新标签页。
